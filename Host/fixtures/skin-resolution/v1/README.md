# Native skin resolver oracles

`native-oracle.json` is generated by
`ThumbleSkinResolverTests.testEmitAndroidSkinAppearanceOracle` using the actual
Swift `ThumbleSkin.appearance` and `ThumbleSkinResolver` implementations. It is not
an Android-authored expected result. The four Website archives are read unchanged;
the synthetic package is unit-test data, including a non-renderable image payload.
This fixture does not validate package decoding or approve any skin artwork.

Coverage:

- Five packages × two orientations × two color schemes × four action sets:
  80 appearances and 560 inferred/explicit-role control cascades.
- Synthetic package × 16 combinations × five local override/baseline modes:
  80 control results, merged style/asset libraries and image hydration stages.
- Eight shapes (including unspecified) × eight corner specifications × three
  override modes: 192 native corner/clamp/silhouette results.

Regenerate from the repository root:

```sh
xcodebuild test -project Thumble.xcodeproj -scheme ThumbleTests -configuration Debug \
  -destination 'platform=macOS,arch=arm64' -derivedDataPath build/StackSafetyDerivedData \
  -only-testing:ThumbleCLITests/ThumbleSkinResolverTests/testEmitAndroidSkinAppearanceOracle \
  -only-testing:ThumbleCLITests/ThumbleSkinResolverTests/testEmitAndroidSkinProfileOracle \
  CODE_SIGNING_ALLOWED=NO COMPILER_INDEX_STORE_ENABLE=NO
cp build/AndroidSkinResolver/native-oracle.json Host/fixtures/skin-resolution/v1/native-oracle.json
cp build/AndroidSkinResolver/native-profile-oracle.json Host/fixtures/skin-resolution/v1/native-profile-oracle.json
./Android/gradlew -p Android testDebugUnitTest assembleDebug assembleDebugAndroidTest lintDebug
```

`Android/testSupport` shares the independent structural oracle assertions between
JVM and instrumentation tests. Test-only Gradle roots include these fixtures; the
production APK does not bundle them. The device suite uses Android's actual JSON
implementation, covering differences from the JVM JSON dependency.

`native-profile-oracle.json` is generated by
`ThumbleSkinResolverTests.testEmitAndroidSkinProfileOracle`. It adds 86 full-profile
results across the 18 native controller template fixtures, a default keypad, a
mixed-kind keypad, opaque future-metadata case and a baseline/local-edit case. Every full result is compared,
with separate assertions that input identities, labels, bindings, control settings
and presentation metadata survive unchanged. Hydration is restricted to native
appearance owners; future element metadata that resembles an image fill stays opaque. It also covers 22 compatibility
cases (including a template revision beyond 32-bit range), all 68 canonical device
canvases, and visible geometry for 22 layouts including the system toggle.

Compatibility cases cover orientation/aspect/role failures, unknown/mismatched
canonical templates, exact captured geometry, missing/duplicate controls, hidden
system controls, size/position/rotation changes, invalid insets/presentation and
missing orientation captures. Full native results prove artwork/background gating
while semantic control styling remains available.

These resolver stages operate on canonical validated model JSON. Full nested
Codable normalization, raw canvas alias normalization, live profile/library UI,
package sync, renderer acceptance and skin application/detachment persistence
remain separate requirements. Synthetic image payloads are non-renderable engine
test data; these fixtures provide no visual review or publishing approval.


`native-model-oracle.json` is generated by
`ThumbleSkinResolverTests.testEmitAndroidSkinModelOracle`. It contains 394 strict
decode/normalization cases: 171 accepted outputs and 223 rejected inputs. Coverage
includes required/optional/null/type behavior, nested duplicate records, fill
bounds, default/empty styles, legacy colors, image byte limits/cap insets, native
Base64 padding, shadow opacity, haptics, Unicode name/legend limits and lone versus
paired JSON surrogates. Large binary expectations use a SHA-256 marker; test
helpers expand deterministic input bytes and compare canonical Base64 plus digest.
Four unchanged Website package skin models are compared with native package outputs.

Regenerate this additional fixture with the same xcodebuild invocation above,
selecting `testEmitAndroidSkinModelOracle`, then copy
`build/AndroidSkinResolver/native-model-oracle.json` to this directory.
The profile oracle also exercises removal of default haptics and the default
joystick presentation after application. Portable native text tables have their
own [provenance and regeneration instructions](../../../../Android/unicode/README.md).


`native-contract-oracle.json` is generated by
`ThumbleSkinResolverTests.testEmitAndroidSkinContractOracle`. It covers 217 typed
compatibility/captured-contract inputs: 56 accepted models and 161 decode
rejections. Native package validation after decode/normalization accepts 49 of
them. The shared tests compare complete normalized models and package acceptance,
not selected geometry fields. Captured controls, presentation, native surfaces,
chrome/container paint, layout matrices, requested appearance and resolved paint
are included. Core Graphics array tails, raw evidence values versus normalized
fills, revision/aspect repair, canonical template/control identities and strict
unknown presentation fields have explicit cases. Three raw JSON cases compare
native duplicate-key behavior, including composed/decomposed spellings.

Regenerate with the same xcodebuild invocation above selecting
`testEmitAndroidSkinContractOracle`, then copy
`build/AndroidSkinResolver/native-contract-oracle.json` into this directory.
The profile oracle additionally checks runtime template matching for canonically
equivalent spellings. The contract device tests verify that malformed captured
metadata cannot replace an installed archive.

These tests do not complete full manifest metadata or profile decoding, live skin
application, persistence/synchronization UI, or native renderer/release acceptance.


### Profile skin lifecycle oracle

`native-lifecycle-oracle.json` is emitted by
`ThumbleSkinResolverTests.testEmitAndroidSkinLifecycleOracle`. It records 44
complete canonical-profile transitions for apply, reapply/switch, edits relative
to baselines and detach with matching/mismatched/missing packages. It includes
primary/explicit orientation slots, both schemes, package-owned data dehydration
and user-owned image preservation. Root `updatedAt` is zeroed for comparison;
other input metadata is preserved. Packages are synthetic resolver fixtures, not
publishable archives or artwork.

Regenerate with the xcodebuild command above selecting
`-only-testing:ThumbleCLITests/ThumbleSkinResolverTests/testEmitAndroidSkinLifecycleOracle`,
then copy `build/AndroidSkinResolver/native-lifecycle-oracle.json` here.
`Android/testSupport/.../SkinLifecycleOracle.kt` compares the complete results on
both JVM and Android API 26. It is test-only and excluded from the production APK.
