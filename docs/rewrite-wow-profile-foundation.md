# WoW profile refresh foundation

This slice supplies the storage use case and optional retained native presentation adapter. It does not start capture, choose a game window, activate a saved controller, deliver phone icons, or enable OS input. CLI/MCP configuration-owner composition is a separate layer.

`WowSyncSession` accepts immutable `WowCapturedFrame` receipts from the existing capture supervisor. Only the frame completing a **new** `WowLiveObserver` receipt supplies the atlas for that intent. A subsequent incomplete frame or repeated pending receipt cannot substitute its atlas. One helper attempt may run at a time; busy observations are rejected without consuming them. Capture status is not advancing game evidence. Callers retain the observer across temporary missing-panel statuses so acknowledged character selection does not reset, while the supervisor's current-receipt fence prevents old captures from committing.

`WowProfileRefresh` runs inside the existing configuration owner. It materializes pooled resources, derives the retained character/flavor UUIDv5 through a trusted port, and sends only the selected raw profile and the same captured atlas to a preparation port. Explicit empty binding overrides remain present. The result must identify exactly one controller profile, the expected character and flavor, and the SHA-256 of the exact supplied existing profile. Existing profile maps are retained; only a newly created profile receives initial maps, with keyboard outputs rejected. A native helper's before/after projections are merged into exact source, preserving opaque values and manual changes. The result is structurally validated and resources are repooled into the ordinary atomic authority transaction.

New character profiles use a virtual production starter18 baseline with the retained character UUIDv5 and minimal WoW metadata. The helper receives this baseline and its explicit gamepad maps as an existing profile, so its SHA/before projection must correlate to those exact supplied bytes even though no profile yet exists in storage. Its before/after presentation delta is merged onto the virtual source before one final authority CAS appends it; normalized compatibility mirrors are preserved alongside the starter's explicit zero-inset geometry and continuous triggers. Saved-map projection admits nonbuiltin presentation mirrors only after checking canonical ID/kind/settings, identical hit geometry, hidden/z-order/haptics and supported analog visual semantics; alternate output declarations, unknown mirror fields or conflicting input semantics fail closed without rewriting source. The original authority absence/revision remains the write guard. Existing user profiles continue through their original exact-source path and are never normalized to this starter.

Each sealed observation pins its first authority revision and source hash. A conflicting retry cannot silently apply the old intent to newer storage. Capture currency, observer receipt, monotonic observation freshness, cancellation and session lifetime are checked again immediately before the synchronous revision CAS. A successful durable commit is acknowledged using that exact observer receipt. If observation freshness fails after the commit, the durable receipt is still returned with `acknowledged: false`; the operation is not reported as rolled back.

Transport ticks establish advancing observations, not authenticated real-game freshness or permission to issue input. Storage writes do not replace or relabel an already active native saved snapshot. Explicit runtime reactivation remains separate.

## Bounds and optional helper

`RetainedWowProfilePreparer` requires an explicit absolute executable path and invokes it with JSON stdin and no arguments. The retained `prepare-owned` schema-2 request is capped at 12 MiB and its reply at 16 MiB. The before-profile and one-profile document retain their individual 8 MiB lossless-JSON bounds. UTF-8 is fatal, duplicate or unknown envelope keys are rejected, and all source/identity checks are repeated by the storage use case. The helper has a 2-second preparation deadline, followed by bounded termination attempts; an unconfirmed exit fences further helper launches. Error messages never contain child stderr, paths, profiles or atlas data.

The pure projection merge retains the existing depth/node/8 MiB document budgets and rejects objects wider than 512 members before doing member lookups. UUID aliases, NFC key collisions and ambiguous opaque removals fail without a write. This is a conservative complexity admission limit, not a truncation or migration.

The adapter permits a locally configured retained headless presentation helper during cutover. It does not bundle that helper or publish any private baseline, source archive or native binary. Standalone public packaging of the helper remains a release gate. The helper requires no desktop GUI or desktop IPC. Its native model/renderer changes remain subject to the repository's constrained-thread stack gates.

## Verification scope

Synthetic tests cover completing-frame atlas correlation, exact opaque values and explicit empty overrides, stable identity arrays, source mismatch, revision conflict, cancellation/stop/expiry before CAS, durable commit with a failed postcommit ACK, and one-pipeline behavior. POSIX synthetic child tests exercise request/reply bounds, malformed UTF-8, duplicate keys, overlap, cancellation and confirmed termination. They do not certify native presentation fidelity, real game capture, phone icon delivery or authenticated game state.

An explicit offline real-helper regression accepts `THUMBLE_TEST_RETAINED_WOW_HELPER=/absolute/retained-helper`. It uses synthetic multi-page action/icon frames and a verified atlas, commits through real SQLite/assets, exercises A/B/A character changes and icon reassignment/back, preserves opaque user edits, and projects18 controls after each playable refresh. A final explicit empty output-map override remains empty and correctly makes the controller unbound. It invokes no capture, permission, GUI or OS input factory. The test is skipped when no helper is explicitly authorized; synthetic CI composition tests remain independent.
