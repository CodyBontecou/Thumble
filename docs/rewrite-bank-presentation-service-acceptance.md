# Bank-aware presentation service acceptance

`PhoneBankPresentationServiceTest` is an opt-in executable witness against a new,
owned recording-only receiver, native pinned TLS listener, Bun service and sole
configuration child. It uses no game, capture, installed app or physical output.
Set `THUMBLE_BANK_PRESENTATION_SERVICE_PROBE` to the absolute executable
`Rewrite/tooling/presentation-service-probe.ts` path, with pinned Bun on PATH,
and run the Android SDK's filtered unit test normally.

The wrapper's explicit `--bank-presentation` mode imports a synthetic South
button and independent continuous triggers through normal validation and source
CAS. All four banks in both themes have distinct verified 32px PNGs. Canonical
mirrors match light/base so normal three-way projection selects variant bytes.
The default wrapper, existing role10 `u`, and geometry-stale `s` commands retain
their prior behavior.

The witness runs both actual UDP and forced TLS fallback. It obtains a served
saved-map baseline and holds South plus both triggers at 1.0 through all eight
metadata/icon batches. A/B/A reads recover the same icon. A control object from
another bank is rejected locally as an icon capability for the current batch.
A normal CAS changes only appearance and labels; old metadata's icon request
receives `presentation_stale`. Every refreshed bank/theme returns changed,
distinct verified bytes under the original installed source/map pin and input
generation/revision. Stale CAS is also rejected while input stays held.

New command `w` waits for the exact held report with the existing one-second
probe ACK budget. Command `g` checks at least 1.5 seconds of held recording
samples, unchanged epochs, zero neutral pulses and recording-only output. Its
reported 350ms TTL is the unchanged underlying probe activation contract, not
an additional Snapshot field. Recording reads are bounded; the wrapper retains
its 60-second lifetime. Product deadlines and sampling remain unchanged.

After native neutral release, operator revocation rejects a secondary phone
before metadata (only hello and credential proof are sent). Existing operator
revocation releases input globally; the test does not call it cosmetic.

An initial new-test version inspected the native snapshot immediately after
asynchronous touch publication, before the held-report ACK. The corrected
setup uses the same bounded ACK barrier as the role10 witness. Failed evidence
is retained separately; no production behavior was changed to make it pass.
