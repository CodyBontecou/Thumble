# Bounded optical capture receipts and supervision

The new contracts, domain receipt and application supervisor form a portable capture boundary. They do not capture a window, request permission, start a real helper, edit authority or acknowledge an observer. The migration oracle is `Sources/Bridge/WoWLiveCapture.swift`; [optical decoding](rewrite-wow-live-v1.md) and [observation acknowledgement](rewrite-wow-observer-v1.md) remain separate.

A trusted future game-only selector assigns a positive uint32 opaque source, never a truncated HWND or caller-selected window/path. `start(source)` issues an increasing uint64 generation, including same-source resize/device-reset restarts. Each request gets an increasing uint64 receipt. Counters never wrap. Constructor seeds only advance local counters; they restore no context or pending work. A fresh child transport must not inherit old queued replies.

The dedicated child request is flat ASCII JSON `{version:1,command:"wow-capture",source,generation,receipt}`, at most256 bytes. A reply echoes all identities with `command:"wow-capture-result"`. `kind:"frame"` requires exactly `frameBase64` and `atlasPNGBase64`; `kind:"status"` instead carries a fixed status. Duplicate/escaped keys, nested or coercible values, extra fields, noncanonical identities/base64 and mismatched receipts fail closed. Maximum reply bytes are `4*ceil(2MiB/3)+1024`. The future adapter must enforce this frame bound before allocation. No raw whole-window pixels, arbitrary paths/windows or payload logging belong in this protocol.

A frame is exactly512 bytes and must pass existing THWL validation. Its same-reply atlas is at most2MiB and a256-square8-bit noninterlaced RGB/RGBA PNG. Container checks cover signature, dimensions, chunk bounds/order, CRCs, at most256 chunks, known critical chunks, IDAT and final IEND. A required `decodeAtlas` port must then actually decode compressed pixels with at most262,400 inflated scanline bytes and262,144 output RGBA bytes, returning exact256-square RGBA. Structural admission alone is insufficient; invalid compressed data rejects the receipt. Bounded metadata/working memory also remains the eventual native decoder adapter's responsibility. No production decoder is composed here.

`WowCapturedFrame` copies frame/PNG together and returns copies through accessors. Immutable identity and `observedAtMs` come from the supervisor. Same-reply association cannot authenticate a fabricated provider or prove which pixels it captured: the future native provider must derive both outputs from one normalized capture and never label raw RGBA as PNG.

The supervisor retains one provider, one in-flight request, one coalesced demand flag and one latest result. Repeated demand coalesces into a single follow-up; superseded intermediate results never enter a queue. New work invalidates previously issued results. `take()` transfers the latest once; `isCurrent(identity)` checks the issued receipt's context and age. Source/restart/stop, newer work, failed/malformed capture or clock regression invalidates it. Child status receipts distinguish permission required, absent game, multiple game windows, missing panel and unavailable provider. A stale consumer identity fails `isCurrent`; it is not a current permission/no-panel result.

Capture health timeout is two seconds, also checked against the absolute deadline on completion if timer dispatch is late. Death, timeout or invalid reply retires the provider and requires a new context. `stop()` returns `stopped` only after termination confirmation; its caller receives fixed `unavailable` after500ms otherwise. Failed/unconfirmed termination still owns the slot, including after late capture completion. No replacement overlaps it; confirmation and detached child listeners are required before replacement. Repeated stop calls share one bounded promise.

An injected monotonic clock and asynchronous owner-queue scheduler keep these lifecycle budgets independent of input. Clock rollback invalidates context without rolling back its high-water mark. Issued/latest receipts expire after two seconds, without query-time refresh. Fresh capture receipts do not advance game liveness: replayed/frozen THWL ticks remain frozen. The eventual authority adapter must still recheck observer identity/freshness, perform its sole-writer CAS and ACK only after successful commit. This supervisor has no ACK/configuration capability or durable recovery.

Fake-child tests with deterministic time and a real bounded synthetic-PNG zlib decoder cover coalescing, delayed/hung/dead children, source/restart/stop invalidation, failed termination, strict payload/CRC/chunk bounds, raster decompression overflow, immutable bytes, counter/clock overflow and replayed game ticks. OS capture permissions, native adapters, real WoW windows/scaling, observation mapping, phone sync and gameplay acceptance remain unfinished launch gates. Manual refresh must remain available.
