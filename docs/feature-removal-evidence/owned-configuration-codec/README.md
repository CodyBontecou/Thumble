# Explicit Rust version-5 configuration reader

The reader accepts only the proposed single-landscape, package-independent version-5 envelope. It validates whole-document bounds, profile and input identities, keyboard/controller binding ownership, canonical/bank appearance and resources. It keeps exact original bytes for interchange and raw profile views for preparation, including unknown metadata, unsigned integers and local launch data. Normal authority startup/installation remains behind its existing v4 validator; shipped format offers remain `[4]`.

The hand-assembled specimen combines a native pooled profile and an existing arcade template. It is not an actual migration result. Its 39 mutation cases cover version markers, missing/foreign identities, nullable defaults, removed fields and aliases, portrait/unknown/custom canvases, timestamps, corrupt bank/resources, credential/retired-artifact roots and binding-map ownership. Provenance hashes and the unchanged source fixtures are verified by `scripts/verify-feature-removal-fixtures.py`.

The full `./scripts/verify-rust-host.sh` passes formatting, clippy, 496 tests and retained target checks, with three native-dependent tests ignored. Three new integration tests consume the 39-case matrix, retain exact input bytes and u64 metadata, resolve all eight states with unchanged geometry/executable fields, prove legacy authority rejection, reject duplicate keys/invalid UTF-8, and exercise the exact 8 MiB input boundary and one byte over. The first rendering assertion incorrectly expected state paint to equal Base; it was corrected to compare identity/geometry/output and assert the state-specific icon. An initial clippy range-style failure was corrected before the final gate.

The required Apple gate passes all 37 existing constrained-stack cases and both Debug builds with unchanged budgets. Apple source did not change in this batch; these results verify retained paths, not an Apple version-5 reader. Android source and device behavior were not changed or tested in this batch.

Native/Android version-5 readers, typed edit/write preservation, portable-export policy, actual transfer admission, raw-backed atomic migration/rollback, active skin/portrait removal and physical-device/live WoW acceptance remain outstanding. No user profile was converted, no version-5 offer was advertised and no deployed service was stopped. Adjacent files contain final log hashes and selected test/build excerpts.
