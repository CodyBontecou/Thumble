# CSS First Light

Example CSS-authored Thumble skin workspace targeting `showcase-controller-v1`.

- `styles/controller.css` — all control styling, written against the `thumble-css-core-1` profile.
- `skin-source.json` — schema 2 workspace pointing at the stylesheet; materials and SVG are not required.
- `reviews/contact-sheet-1.png` — native-renderer contact sheet generated by `skin preview`.

```bash
thumble skin css lint .
thumble skin css computed . --control builtin-jump --scheme dark --state pressed
thumble skin compile . -o build/css-first-light-1.0.0.pocketpad --clean --strict
thumble skin validate build/css-first-light-1.0.0.pocketpad --strict
thumble skin preview . -o reviews/contact-sheet-1.png \
  --all-variants --all-states --native-renderer --contact-sheet --columns 4
```

This is an authoring example, not a published skin. `reviews/human-approval.json` remains `pending`; publication requires human approval of the exact contact sheet and package hash.
