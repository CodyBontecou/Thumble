# Controller versus keyboard and mouse comparison

Checked October 26, 2026.

- [ConsolePort official listing](https://www.curseforge.com/wow/addons/console-port): controller interface, action bindings, menus and an on-screen keyboard are documented. The comparison leaves exact behavior conditional on installed releases and configuration.
- [Apple controller connections](https://support.apple.com/en-us/111099): wired/Bluetooth connection routes and support varying by device and app.
- Existing Thumble setup and release records: phone supplies input, Mac displays WoW, no video streaming; public phone downloads coming soon; documented companion-addon 0.1.2 scope Classic Era 1.15.9.

Workflow selection and mixed-input checks are editorial recommendations, not measured performance findings. No latency, raid/PvP, accessibility or ergonomic benefit is claimed. No gameplay or production signup was performed.
