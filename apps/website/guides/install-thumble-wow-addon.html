WoW controller guide

Install the Thumble WoW addon with CurseForge

In CurseForge, choose your WoW installation, search for Thumble by codybontecou and install a release that matches that client. Enable Thumble alongside ConsolePort in WoW. The documented 0.1.2 release supports Classic Era 1.15.9; do not use that file as a general release for other WoW clients.

Which part do you need?

The Thumble addon is one part of the setup. Installing it does not install the phone app or Mac receiver, and it does not replace ConsolePort.

  • ConsolePort: your WoW controller interface, actions and modifier bindings.
  • Thumble addon: companion support for Mac gamepad recovery and ConsolePort spell labels and modifier layers in the documented release.
  • Thumble Receiver: the Mac software that receives phone input.
  • Thumble phone app: the touchscreen controller. Android is on Google Play; the iPhone app is coming soon.

The receiver and phone connection are covered in the Thumble setup guide. For the game interface, start with ConsolePort setup on Mac.

Check the release before installing

Thumble 0.1.2 is documented for Classic Era 1.15.9. Check the official Thumble listing for a file matching your exact client. The release scope was recorded on October 25, 2026; newer releases may have different requirements.

A ConsolePort file existing for another game flavor does not make the Classic Era Thumble file compatible with it. If no matching Thumble release is offered, continue with the applicable ConsolePort setup and the manual recovery instructions.

Install and enable both addons

  1. Open the CurseForge app on your Mac and select World of Warcraft.
  2. Select the installation you actually launch. Use game detection or add it manually if needed.
  3. Open Get More Addons and search for Thumble by codybontecou, project 1763832. You can also open the direct Thumble listing.
  4. Check the release’s game version, then install the matching file.
  5. Install ConsolePort for the same installation if it is not already installed.
  6. Restart WoW for the first installation. At character selection, open AddOns and enable Thumble and ConsolePort.

Keep both addons updated from My Addons in the selected installation. For an update to an addon already loaded in your session, the current setup reference uses /reload. Use a full restart for the first install.

Check gamepad discovery

With the phone paired and the receiver running, type /thumble discovery in WoW chat to inspect recovery status. Keep ConsolePort enabled, release the controller and leave combat before testing recovery.

Recovery waits for neutral controls and defers while in combat. After recovery, test movement and stopping before checking camera, actions, modifiers and menus. Read the five checks in full if this is your first session.

The addon does not cast spells, press gameplay buttons or automatically change your bindings. The optional /thumble tools provide character export and binding review; they are not required for the default controller.

Installation questions

Why can’t I find Thumble in CurseForge?

Open the direct listing and check the game client selected in CurseForge. If there is no release for that client, do not force an incompatible file into it.

Do I need Thumble Bridge as well?

No second copy is needed when upgrading from Thumble Bridge. The listing is named Thumble; the internal folder and saved settings retain the older name for compatibility.

Will the addon assign my spells?

Choose your actions in ConsolePort. The documented Thumble release adds spell-label and modifier-layer sync, but a displayed label does not itself create an in-game binding.

Can I use it without the phone app?

Installing the addon does not provide phone input. For Thumble’s phone controller you also need the receiver and phone app. Thumble for Android is on Google Play; the iPhone app is coming soon.
