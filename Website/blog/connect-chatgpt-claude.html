Local controller tools

Build with the tools on your Mac.

Thumble’s hosted connector and relay are retired. The desktop editor, CLI, and local stdio MCP adapter remain available for designing your controller.

Keep editing locally

Arrange controls and edit appearance in the Mac editor. Use the CLI or a local terminal agent to inspect profiles, install templates, generate layouts, and make targeted changes. The local MCP adapter uses stdio and the host’s private control socket.

thumble profile list --ids
thumble template list
thumble profile export --all -o thumble-profiles.json

Appearance editing, design tools, haptics, on-phone editing, and the WoW addon remain part of Thumble. Hosted OAuth connections, cloud builder sessions, and remote relays are no longer offered.

If an earlier installation started a background relay, thumble relay uninstall removes that old local LaunchAgent. It does not change your controller profiles.
