A few things to know

Before you jump in.

What do I need to use Thumble?

An iPhone running iOS 17 or later and the Mac helper. Pair the two devices, allow Mac Accessibility access, and keep the app you want to control in focus. See the setup guide.

Can I use it with any game?

Keyboard and pointer layouts use your own bindings. Gamepad output requires an authorized signed Mac receiver, and compatibility is still being validated. The game layouts above are app previews, not a guarantee of game support. See the output guide.

Can I design my own keypad?

Yes. Arrange controls, edit colors and effects, add artwork, and tune haptics in the Mac editor. Use the CLI and local MCP tools to script your designs. Start with the editor guide.

Where can I follow development?

Read the development journal for feature updates and join the launch list below for beta invitations and release news.
