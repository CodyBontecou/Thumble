details

one phone, many control surfaces.

01

layouts that fit

Save portrait and landscape designs, arrange controls in layers and groups, and calibrate thumb reach on iPhone. Practice Mode lets you try a layout without sending input.

02

edit with an assistant

Describe a controller to ChatGPT, Claude, or a terminal agent. Draft, preview, and refine the layout with Thumble’s MCP and CLI tools, then sync it to your iPhone.

03

low latency

Authenticated UDP carries compact input frames for responsiveness while WebSocket mirroring keeps button state recoverable if packets drop.

04

CLI included

Generate profiles, install templates, import/export JSON, set bindings, check status, restart the helper, and test taps from the terminal.
