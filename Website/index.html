details

one phone, many control surfaces.

01

macOS helper

Runs the pairing server, advertises Smart Connect over Bonjour, edits keypad setups, and injects keyboard and pointer events with Accessibility permission.

02

iOS controller

Shows your synced keypad, supports multitouch controls, haptics, profile switching, offline saved layouts, and quick layout edits for freeform designs.

03

low latency

Authenticated UDP carries compact input frames for responsiveness while WebSocket mirroring keeps button state recoverable if packets drop.

04

CLI included

Generate profiles, install templates, import/export JSON, set bindings, check status, restart the helper, and test taps from the terminal.
