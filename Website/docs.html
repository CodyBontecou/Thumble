overview

What Thumble does

Thumble turns an iPhone into a programmable control surface for a Mac. The macOS helper hosts a local pairing server, stores keypad profiles, and sends keyboard, pointer, or virtual gamepad output to the focused app. The iOS app displays the synced keypad and sends low-latency button, joystick, trigger, and trackpad input over your local network or a nearby peer-to-peer path.

macOS

Helper + editor

Grant Accessibility, pair iPhones, manage profiles, record shortcuts, and edit each keypad visually.

iOS

Touch controller

Use synced profiles, switch setups, export keypads, toggle haptics, and make quick freeform layout edits.

CLI

Scriptable parity

Generate, import, export, select, bind, inspect, and test keypads from the terminal.

requirements

What you need

  • macOS 14 or newer running Thumble Mac.
  • iOS 17 or newer running Thumble on iPhone.
  • Same local network or nearby peer-to-peer for Smart Connect, QR pairing, and realtime input.
  • Accessibility permission on Mac so Thumble can inject keyboard and pointer events.
  • Local Network permission if iOS or macOS prompts for it.
  • Camera permission on iPhone only if you scan the Mac QR code.

setup

First-run setup

  1. Open Thumble Mac.

    The Home screen shows readiness for Accessibility, the helper server, and iPhone pairing. A first-run setup guide walks through the same steps.

  2. Enable Accessibility.

    Click Request Accessibility Permission or Open Accessibility Settings, then enable Thumble Mac in System Settings → Privacy & Security → Accessibility.

  3. Open Thumble on iPhone.

    The iOS onboarding explains Local Network and Camera prompts. Tap Smart Connect, or use Scan Mac QR Code if this is the first pairing. For airplane/offline use, keep Wi‑Fi and Bluetooth enabled after enabling Airplane Mode so peer-to-peer discovery can run.

  4. Pair securely.

    Scan the QR code on the Mac, or manually enter a displayed ws://<mac-ip>:<port> address. If prompted, type the six-digit code shown on Thumble Mac.

  5. Focus the target Mac app.

    After pairing, Thumble controls whichever Mac app is currently focused. Use Release All if a key ever feels stuck.

mac app

Home, Keypad, and Settings

The Mac app is the source of truth for saved keypads and bindings. It runs the server, displays QR and manual pairing information, previews the active keypad, and exposes diagnostics.

Home

Use Home to check readiness, copy the pairing code, scan QR from the iPhone, switch profiles, make a setup the default, and perform quick local shortcut tests.

Keypad

Use Keypad to visually edit layouts, manage profiles, record shortcuts, configure output mode, and sync changes to the connected iPhone.

Settings

Use Settings for appearance defaults, input diagnostics, local addresses, server restart/stop, and advanced connection troubleshooting.

ios app

Connection screen and controller screen

The iOS app starts on a connection screen unless it can reconnect to a trusted Mac or show a saved keypad offline.

Connection screen

Use Smart Connect for remembered Macs, scan a Mac QR code for first-time pairing, or manually enter host and port. You can also view the last synced keypad when offline.

Controller screen

The top bar shows connection status, the active keypad setup, edit lock, haptics and appearance settings, export actions, and Disconnect. Swipe down from the top edge if the bar is hidden.

Offline saved keypad

After a successful sync, iPhone can display saved profiles even when Thumble Mac is closed. Input only controls the Mac while connected.

editor

Build a keypad setup

A setup is a saved profile containing layout, output mode, bindings, colors, haptics, style tokens, assets, and per-orientation variants. Edits on Mac save automatically and sync to the paired iPhone.

profiles

Setups and templates

Create, duplicate, delete, switch, import, export, and mark defaults. The active setup is sent to the iPhone and can be changed from either device.

canvas

Device frames

Match the editor to the connected iPhone, choose any supported iPhone display class, or use a custom canvas size. Portrait and landscape variants are saved separately.

layout

Controls and grid

Add buttons, joysticks, triggers, and trackpads. Drag on the canvas, nudge, align, distribute, layer, group, and use snap/grid preferences for precision.

design

Styles and haptics

Customize fills, strokes, pressed states, icons, glows, reusable style tokens, background fills, gradients, image fills, and per-control haptic patterns.

Typical editor workflow

  1. Choose a setup.

    Start from the default keypad, install a template, or generate/import a profile.

  2. Pick the device canvas.

    Use the connected iPhone frame or choose a model and orientation manually.

  3. Place controls.

    Add controls, resize them, and test hit targets with the preview.

  4. Record outputs.

    Select a control, click the shortcut field, press the desired Mac keystroke sequence, and pause to save.

  5. Sync and test.

    Connect the iPhone, focus the target Mac app, and press controls. Use Release All if you change apps mid-press.

game layouts

Build around the controls you actually use

Use the Mac editor to combine buttons, joysticks, triggers, and trackpads. Save separate portrait and landscape variants, use groups and layers to organize controls, and keep friendly labels separate from their outputs. Start with a template or ask an AI assistant to draft a layout.

League of Legends: a custom companion pad

There is no built-in League preset. Create a keyboard layout that matches your own game settings: group ability keys together, give summoner spells and items their own buttons, and add controls for your chosen ping shortcuts. Add a trackpad if you want relative pointer movement, tap-to-click, two-finger right click, or scrolling.

Record the actual shortcuts from your game settings rather than assuming defaults. Test with the game focused, and refine spacing and size in the editor. This is a configurable keyboard/pointer surface; it does not read game state or provide automatic targeting.

Fit the layout to your hands

On iPhone, edit control placement directly to fit your reach. Practice Mode keeps touch feedback and haptics active while suppressing keyboard, pointer, and controller output. These existing tools also help test more complex layouts before using them in a game.

in development / World of Warcraft

Two ways to build a WoW setup

The following work is newer than TestFlight 1.0.0 (6). Use matching development builds of the Mac helper and iPhone app; the July beta is not a compatibility guarantee.

WoW Forever controller template

Create a setup from WoW Forever in the Mac or iPhone editor, or install it with the CLI. The template has two analog sticks, D-pad, ABXY, shoulders, held triggers, stick clicks, View, and Menu, with separate portrait and landscape layouts. Duplicate and name profiles for each character or talent build.

thumble template install wowForever --name "WoW Mage Frost"
thumble profile duplicate "WoW Mage Frost" "WoW Mage Fire"
thumble gamepad doctor
thumble gamepad status --json

Enable the game’s native Gamepad interface and assign abilities in WoW. Thumble sends physical press/release state; WoW owns ability assignments, targeting, and action-bar pages. There is no automatic class/spec detection or live spell synchronization.

Controller availability

Virtual gamepad output on Mac needs an Apple-authorized signed receiver. Signing and live WoW recognition remain acceptance gates; automated template tests do not establish game compatibility. See the controller status and verification guide.

Thumble Link: import your keyboard bindings

The experimental addon targets Forever interface 16001 and Blizzard’s default action bars. Install Thumble Link, type /thumble outside combat, select bars, and generate an export. In the matching Mac app, open Thumble Link…, paste the code, choose Review Import, then Create Setup.

thumble wow import --clipboard --dry-run
thumble wow import --clipboard

Re-export after rebinding. Refresh updates the same character setup while preserving positions, styling, deleted controls, and manually edited labels or outputs. This is a copy/paste snapshot for keyboard output, separate from native controller mode. It does not sync cooldowns, live forms, or ability pictures. Live acceptance in the exact Forever client is still pending.

In a development checkout containing the addon, copy Addons/ThumbleLink into the supported client’s Interface/AddOns directory. The included README documents supported bars, skipped bindings, and refresh behavior. This addon is not bundled with the current beta.

experimental / developer setup

Keyboard and mouse on Windows and Linux

The separate native Rust receiver pairs with the iPhone over a local network and delivers keyboard chords, relative pointer movement, clicks, and scrolling. Native desktop input has been verified with an actual iPhone on both platforms. It does not include virtual gamepad output, rumble, or the Mac editor/MCP tools.

From a development checkout containing thumble-receiver, use Rust 1.88 or newer to build it on the target platform:

cargo build --locked --release --manifest-path Host/Cargo.toml -p thumble-receiver

Run the resulting executable with run as your normal desktop user. Windows uses SendInput; Linux requires access to a virtual uinput keyboard/mouse. Follow the platform permissions and firewall instructions in the checkout’s docs/cross-platform-receiver.md before pairing. Keep both devices on a trusted network.

The iPhone uses reliable WebSocket input with this receiver. Setup and packaging are separate from the Mac download on this site; use the matching development client rather than assuming compatibility with the July beta.

appearance

Design your keypad directly

Use the Mac editor to change control colors, gradients, icons, typography, artwork, and pressed-state effects. Reusable styles, layers, and groups help keep a design consistent. Light and dark appearance remain part of your setup.

Adjust control placement on your phone, and use Practice Mode to try the layout and haptics before sending input. See the editor guide for the editing workflow.

The public skin directory and package downloads have been retired. Your saved layouts and input bindings remain yours.

outputs

Keyboard, pointer, and controller output

Each setup can use keyboard, controller, or custom output mode without replacing its saved bindings. Controller controls include two analog sticks, independent triggers, D-pad, buttons, and stick clicks. Tune stick dead zones, sensitivity, and inversion in the editor.

Mac virtual controller support is implemented, but requires the Apple-granted com.apple.developer.hid.virtual.device signing entitlement. GameController, SDL, Steam, and individual game recognition still require validation; support for every game is not established. Keyboard and pointer output remain available in normal builds.

Shortcut recording tips

  • Press Control + B to save a modifier combo like ⌃B.
  • Press a combo, release it, then press another key to create prefix sequences such as ⌃B H.
  • Modifier-only shortcuts save when you press and release the modifier key.
  • Use Default for one control or Reset All to restore starter bindings.

cli

Script Thumble with thumble

The CLI mirrors the saved-configuration features in the Mac Keypad editor and adds runtime helper commands for automation and debugging. Existing automation can continue using the thumbconsole and pocketpad compatibility executables.

If thumble is not already on PATH, build it from a source checkout to a predictable location:

xcodebuild -project Thumble.xcodeproj \
  -scheme ThumbleCLI \
  -destination 'platform=macOS' \
  -derivedDataPath build/DerivedData build
export PATH="$PWD/build/DerivedData/Build/Products/Debug:$PATH"
thumble --help
thumble profile list --ids
thumble template list
thumble template install snes --name "SNES Browser Controls" --default
thumble profile export --all -o thumble-profiles.json
thumble profile import thumble-profiles.json
thumble binding set focus --sequence 'Control+B,H'
thumble output mode keyboard
thumble element add joystick --label "Right Stick" --up custom1 --down custom2 --left custom3 --right custom4
thumble element set jump --label A --shape circle --width 1.2 --height 1.2

Runtime helper commands

thumble server start
thumble layout preview -o /tmp/keypad-preview.png
thumble status --json
thumble server restart
thumble pairing payload
thumble accessibility status
thumble test tap jump
thumble release-all

Use the local receiver for pairing and input, and CLI/MCP for saved configuration. layout preview renders the saved layout to an artifact without a desktop window or Screen Recording access. Desktop window, editor-view and onboarding replay commands have been retired.

ai agents

Tell an agent what you want, not how to click

Thumble includes a repository SKILL.md for terminal-capable agents. It explains how to choose between game generation, templates, targeted profile editing, layout repair and runtime diagnostics while avoiding unsafe UI automation.

1 · context

Give it the skill

Tell the agent to read the local SKILL.md, or install that file in the skill directory supported by your agent host.

2 · outcome

Describe the result

Name the game or app, important controls, preferred orientation, and whether the agent may install, select, or default the profile.

3 · evidence

Require verification

Ask for a dry-run or preview, layout validation, final bindings, confidence/source, and confirmation of what actually synced.

Copy this starter prompt

Read /absolute/path/to/Thumble/SKILL.md, then use the
thumble CLI to create a landscape keypad for Celeste.
Research the default Mac keyboard controls, inspect my profiles,
and dry-run before installing. Preserve unrelated profiles,
validate the final layout, and report the source, confidence,
bindings, whether it became selected/default, and whether sync
could be confirmed. Do not use UI automation.

The reliable agent loop

  1. Inspect.

    Run profile list, profile show active --json, and status --json before editing.

  2. Preview.

    Use generate --dry-run, layout validate, and layout preview when available.

  3. Apply.

    Make only the requested profile, binding, output, layout, or appearance changes. Generation selects and defaults a profile unless the agent passes --no-select or --no-default.

  4. Verify.

    Re-read the saved profile and bindings, rerun layout checks, and distinguish saved configuration from confirmed iPhone sync or physical-device feel.

Safe boundaries to include

  • Use the CLI instead of clicking through the Mac or iPhone UI.
  • Use thumble layout preview -o preview.png for visual checks of the saved design.
  • Ask before launching apps, opening System Settings, triggering permission prompts, restarting the server, or sending test input.
  • Treat test tap|down|up as real output to the currently focused Mac app, and use release-all if a test is interrupted.
  • Inspect before deleting/resetting profiles, clearing bindings, or replacing output modes. Export all profiles before a broad migration or reset.

See the complete Using Thumble with an AI agent guide for reusable instruction-file snippets and copy-paste prompts for games, productivity pads, layout repair, diagnostics, and appearance editing. Hosted connectors are retired; see the local controller tools guide.

troubleshooting

Fix common setup issues

Smart Connect does not find my Mac

Make sure Thumble Mac is running, Local Network permission is allowed, and both devices are on the same Wi‑Fi network or have Wi‑Fi/Bluetooth enabled nearby for peer-to-peer. Use QR pairing as a fallback.

QR pairing fails

Confirm the iPhone camera permission is allowed. If the code still fails, manually enter one of the Mac helper's ws:// addresses and use the six-digit code shown on Mac.

Buttons press but nothing happens on Mac

Re-check Accessibility permission for Thumble Mac, then refresh the permission status in the app. Also confirm the target Mac app is focused.

A key feels stuck

Tap Release All in the iPhone settings menu, the Mac Home quick actions, or run thumble release-all. Thumble also releases held keys on disconnect, server stop, app background, and heartbeat timeout.

The virtual gamepad does not appear in games

Keyboard and pointer output work in normal builds. System-visible virtual controller output requires the app to be signed with Apple's com.apple.developer.hid.virtual.device entitlement.

safety

Local, authenticated, and recoverable input

  • Pairing uses a six-digit setup challenge and trusted reconnect token.
  • Input travels over the local network or nearby peer-to-peer; Smart Connect advertises as _pocketpad._tcp.
  • Button state transitions use compact authenticated UDP frames with WebSocket mirroring for recovery.
  • macOS releases held keys after heartbeat timeout, disconnect, server stop, manual Release All, and app quit.
  • iOS sends a best-effort Release All when disconnecting, backgrounding, or becoming inactive.

faq

Frequently asked questions

Is Thumble only for games?

No. It works well for games, but it is also useful for terminal shortcuts, tmux prefixes, Cursor commands, window management, browser actions, and any Mac app that accepts keyboard or pointer input.

Can I use it without the Mac app open?

The iPhone can view saved keypads offline. Controlling the Mac requires the local receiver to be running and connected; start it with thumble server start. A desktop window is not required.

Can I back up my layouts?

Yes. In Thumble Mac, open the Keypad editor's Export menu and export the current setup or all setups as JSON. You can also export from iPhone or use thumble profile export --all from the CLI. Imports use the same versioned Thumble keypad configuration envelope.

Can I make game-specific profiles?

Yes. Install templates, generate a profile from a known game, or create an agent-provided JSON spec and import it with the CLI.

Do appearance edits change my bindings?

Appearance settings and input bindings are edited separately. Changing colors, icons, or effects keeps your assigned shortcuts and controller inputs.
